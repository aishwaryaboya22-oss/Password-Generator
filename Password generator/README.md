# 🔐 Password Generator (Python)

## 📌 Description

This is a simple Python project that generates a strong and random password using letters, numbers, and special characters.

## 🚀 Features

* Generates secure random passwords
* User can choose password length
* Uses letters, digits, and symbols

## 🛠️ Technologies Used

* Python

## 📂 Project Files

* `password_generator.py` → Main Python program

## ▶️ How to Run

1. Install Python on your system
2. Open terminal or VS Code
3. Run the file:

   ```
   python password_generator.py
   ```
4. Enter the desired password length
5. Get your generated password

## 💡 Example Output

```
Enter password length: 8
Generated Password: A9@kL2#p
```
